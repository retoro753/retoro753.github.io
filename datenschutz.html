Datenschutz

> Kurz gesagt

Diese Website setzt keine Cookies, zeigt keine Werbung und verfolgt dich nicht über andere Seiten hinweg. Einzige Statistik ist ein einfacher Besucherzähler mit GoatCounter.

> Besucherzähler mit GoatCounter

GoatCounter ist ein datenschutzfreundlicher Open-Source-Dienst für Besucherstatistiken. Ich nutze ihn nur für eine Sache: um zu sehen, wie viele Leute die Seite besuchen, und um diese Zahl unten im Besucherzähler anzuzeigen.

So funktioniert es:

  • Bei jedem Seitenaufruf lädt dein Browser ein unsichtbares 1×1-Bild von retr0.goatcounter.com.
  • Dabei wird übermittelt, welche Seite du aufrufst. Technisch bedingt sieht GoatCounter dabei auch deine IP-Adresse und deine Browser-Kennung.
  • Laut GoatCounter werden daraus Besuche gezählt, ohne Cookies und ohne personenbezogene Daten dauerhaft zu speichern. Abgeleitet werden höchstens grobe Angaben wie Browser-Typ oder Land.
  • Es wird kein fremdes Skript geladen, nur dieses Bild.

Wenn du nicht mitgezählt werden willst, blockiert ein üblicher Adblocker GoatCounter zuverlässig. Die Seite funktioniert trotzdem vollständig.

> Weitere Dienste

  • GitHub Pages: Die Website liegt bei GitHub. Wie bei jedem Webserver verarbeitet GitHub beim Aufruf deine IP-Adresse, um die Seite auszuliefern.
  • TryHackMe: Das Profil-Badge auf der Startseite wird direkt von tryhackme.com geladen. Dabei erhält TryHackMe deine IP-Adresse.
  • Schriften: Die Schriften liegen auf dieser Seite selbst. Es gibt keine Verbindung zu Google Fonts.

> In deinem Browser

Deine Sprachwahl (DE/EN) wird nur lokal in deinem Browser gespeichert (localStorage), damit sie beim nächsten Besuch erhalten bleibt. Sie wird nirgendwohin übertragen.

Privacy

> In short

This website sets no cookies, shows no ads and doesn't track you across other sites. The only statistic is a simple visitor counter using GoatCounter.

> Visitor counter with GoatCounter

GoatCounter is a privacy-friendly, open-source service for visitor statistics. I use it for one thing only: to see how many people visit the site and to show that number in the visitor counter at the bottom.

How it works:

  • On every page view, your browser loads an invisible 1×1 image from retr0.goatcounter.com.
  • This transmits which page you are viewing. For technical reasons, GoatCounter also sees your IP address and your browser's user agent.
  • According to GoatCounter, visits are counted from this without cookies and without persistently storing personal data. At most, rough details like browser type or country are derived.
  • No third-party script is loaded, only this image.

If you don't want to be counted, a common ad blocker reliably blocks GoatCounter. The site still works completely.

> Other services

  • GitHub Pages: The website is hosted by GitHub. Like any web server, GitHub processes your IP address to deliver the page.
  • TryHackMe: The profile badge on the home page is loaded directly from tryhackme.com, which means TryHackMe receives your IP address.
  • Fonts: The fonts are hosted on this site itself. There is no connection to Google Fonts.

> In your browser

Your language choice (DE/EN) is only stored locally in your browser (localStorage) so it's remembered on your next visit. It is never sent anywhere.
