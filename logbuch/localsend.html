> Kurz gesagt

LocalSend ist eine kostenlose Open-Source-Alternative zu AirDrop, die nicht nur zwischen Apple-Geräten funktioniert, sondern zwischen Windows, macOS, Linux, Android und iPhone. Die Dateien gehen direkt von Gerät zu Gerät über das eigene WLAN. Kein Internet, keine Cloud, kein Konto.

> Wie ich darauf gestoßen bin

LocalSend ist bei Omarchy vorinstalliert und richtig gut eingebunden:

  • Super + Ctrl + S öffnet das Teilen-Menü.
  • Im Dateimanager per Rechtsklick auf Send via LocalSend.
  • Im Terminal mit omarchy share file, omarchy share folder oder omarchy share clipboard.
  • Die Firewall von Omarchy ist ab Werk zu, nur der Port von LocalSend ist offen. Es funktioniert also direkt nach der Installation.

> So funktioniert es

  • Alle Geräte im selben WLAN finden sich automatisch. Man wählt Dateien aus und tippt auf das Zielgerät.
  • Jeder Dateityp geht: Fotos, Videos, Dokumente, auch einfach Text.
  • Übertragen wird mit voller WLAN-Geschwindigkeit, ohne Größenlimit.
  • Die Verbindung ist per HTTPS verschlüsselt. Jedes Gerät erzeugt dafür sein eigenes Zertifikat.
  • Optional lässt sich eine PIN einstellen, die der Sender eingeben muss.

> Coole Extras

  • Webversion: Unter web.localsend.org läuft LocalSend direkt im Browser, praktisch auf fremden Rechnern ohne Installation.
  • Komplett kostenlos: Open Source (Apache-2.0-Lizenz), ohne Werbung, ohne Tracking.
  • Offenes Protokoll: Das Übertragungsprotokoll ist öffentlich dokumentiert, es gibt sogar eigene Umsetzungen von anderen Entwicklern.

> Gut zu wissen

  • Es klappt nur, wenn beide Geräte im selben Netzwerk sind. Übers Internet verschickt LocalSend nichts.
  • In öffentlichen WLANs, etwa im Café oder Hotel, sehen dich andere LocalSend-Nutzer im selben Netz. Dort lieber die PIN einschalten oder die App schließen.
  • Klappt die Suche nicht, blockiert oft die Firewall. LocalSend nutzt standardmäßig Port 53317.

> In short

LocalSend is a free, open-source alternative to AirDrop that doesn't just work between Apple devices, but between Windows, macOS, Linux, Android and iPhone. Files go straight from device to device over your own Wi-Fi. No internet, no cloud, no account.

> How I found it

LocalSend comes preinstalled with Omarchy and is nicely integrated:

  • Super + Ctrl + S opens the share menu.
  • In the file manager, right-click and choose Send via LocalSend.
  • In the terminal with omarchy share file, omarchy share folder or omarchy share clipboard.
  • Omarchy's firewall is closed by default except for LocalSend's port, so it works right after installation.

> How it works

  • All devices on the same Wi-Fi find each other automatically. Pick your files and tap the target device.
  • Any file type works: photos, videos, documents, even plain text.
  • Transfers run at full Wi-Fi speed, with no size limit.
  • The connection is encrypted with HTTPS. Each device generates its own certificate for that.
  • You can optionally set a PIN that the sender has to enter.

> Cool extras

  • Web version: web.localsend.org runs LocalSend right in the browser, handy on other people's computers without installing anything.
  • Completely free: open source (Apache 2.0 license), no ads, no tracking.
  • Open protocol: the transfer protocol is publicly documented, and other developers have even built their own implementations.

> Good to know

  • It only works when both devices are on the same network. LocalSend doesn't send anything over the internet.
  • On public Wi-Fi, like in a café or hotel, other LocalSend users on the same network can see you. Turn on the PIN there or close the app.
  • If devices don't show up, the firewall is often the culprit. LocalSend uses port 53317 by default.
