> Kurz gesagt

Cryptomator ist ein Open-Source-Tool, mit dem man fast jeden Cloud-Speicher sicher nutzen kann. Die Dateien werden auf dem eigenen Gerät verschlüsselt, bevor sie hochgeladen werden. Der Cloud-Anbieter sieht nur Datensalat. Damit lassen sich auch Google Drive oder andere kostenlose Angebote nutzen, ohne ihnen die eigenen Daten anzuvertrauen.

> Das Problem

Die meisten Cloud-Anbieter verschlüsseln zwar ihre Server, besitzen aber selbst den Schlüssel. Sie könnten die Dateien also lesen, durchsuchen oder bei einem Datenleck preisgeben.

> So funktioniert es

  • Man legt im Cloud-Ordner einen Tresor an und gibt ihm ein Passwort.
  • Nach dem Entsperren erscheint der Tresor wie ein normales Laufwerk. Alles, was man dort ablegt, wird automatisch verschlüsselt.
  • Verschlüsselt werden Inhalte und Dateinamen, mit AES und 256-Bit-Schlüsseln. Auch die Ordnerstruktur wird verschleiert.
  • Kein Konto, keine Registrierung, kein eigener Server: Der Schlüssel bleibt bei dir.
  • Der Code ist öffentlich auf GitHub, und die Software wurde von unabhängigen Sicherheitsforschern geprüft.

> Auf dem Handy

Die iPhone-App kann Tresore direkt aus der Cloud öffnen, bequem per Face ID oder Touch ID, und ist in die Dateien-App eingebunden. Eine Android-App gibt es ebenfalls. Die Desktop-Version ist kostenlos, für die Vollversion der iPhone-App zahlt man einmalig einen kleinen Betrag.

> Gut zu wissen

  • Passwort weg = Daten weg. Es gibt keine Hintertür. Das Passwort gehört in einen Passwortmanager.
  • Der Anbieter sieht zwar keine Inhalte und Namen, aber noch, wie viele Dateien es ungefähr gibt, wie groß sie sind und wann sie sich ändern.
  • Cryptomator schützt die Dateien in der Cloud. Ein mit Schadsoftware befallenes Gerät, auf dem der Tresor gerade offen ist, schützt es nicht.

> In short

Cryptomator is an open-source tool that lets you use almost any cloud storage securely. Files are encrypted on your own device before they are uploaded, so the cloud provider only sees gibberish. That way you can even use Google Drive or other free services without trusting them with your data.

> The problem

Most cloud providers do encrypt their servers, but they hold the key themselves. So they could read or scan your files, or expose them in a data breach.

> How it works

  • You create a vault inside your cloud folder and give it a password.
  • Once unlocked, the vault shows up like a normal drive. Everything you put there is encrypted automatically.
  • Both contents and file names are encrypted, using AES with 256-bit keys. The folder structure is obscured as well.
  • No account, no sign-up, no server of its own: the key stays with you.
  • The code is public on GitHub, and the software has been reviewed by independent security researchers.

> On your phone

The iPhone app can open vaults straight from the cloud, conveniently with Face ID or Touch ID, and is built into the Files app. There is an Android app too. The desktop version is free; the full version of the iPhone app is a small one-time purchase.

> Good to know

  • Lost password = lost data. There is no backdoor. Keep the password in a password manager.
  • The provider can't see contents or names, but can still roughly see how many files there are, how big they are and when they change.
  • Cryptomator protects your files in the cloud. It can't protect a malware-infected device while the vault is open on it.
